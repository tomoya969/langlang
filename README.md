# langlang

予習なしで、ゲーム感覚の反復を続けるうちに、日常会話に困らない語彙まで到達するためのローカルの語学学習アプリ。
最初の対象は韓国語（日本語話者向け）。設計は `docs/plan.md`、AI 向けのルールは `CLAUDE.md`。

## 今の状態

**L1 の教材と学習の記録がそろった段階。** `content/ko/` は国立国語院の学習用語彙リストをもとに `tools/`（`uv run langlang-build`）で作った L1 の教材（39 ユニット・1,000 語・547 文。すべて検算を通ったか、人が決めたもの）。L2 はユニット分けと文法リストまで。
学習の記録は `records/langlang.db`（SQLite・FSRS）に保存する（単語の面、文の段階、取り違え、AI の判定と解説）。苦手は記録からその場で数える。教材の作り方は `content/README.md`、決めたことの経緯は `docs/design.md`。

## セットアップ

- uv（`curl -LsSf https://astral.sh/uv/install.sh | sh`）
- ネイティブ版 Claude Code（`claude` コマンド）。AI を使う機能を動かすときだけ

```text
uv sync
uv run langlang serve          # http://127.0.0.1:8766/ をブラウザで開く（Ctrl+C で止める）
uv run langlang validate       # 教材の整合を確かめる
uv run langlang-build status   # 教材づくりがどこまで済んだか（作り方は content/README.md）
uv run pytest                  # app/ と tools/ のテスト
node --test 'static/**/*.test.js'   # 画面の部品（ハングルの合成、矢印ゲームの列）のテスト
```

## 画面

| URL | 画面 |
| --- | --- |
| `/` | ポータル。言語ごとのカード（次のユニット・今日の分・進み）から言語のホームか学習へ。右上に「設定」 |
| `/settings` | 設定。表示（テーマ。全言語共通でこのブラウザに残る）と、言語ごとの学習の設定（新出の数、苦手枠、単語と文の復習の上限、始めるレベル、反応時間の基準、読み上げ、キーボードの表示） |
| `/ko` | 言語のホーム。今日の学習の見通し（復習・新出・目安の時間）と「始める」、レベルの進み、苦手の数、ユニット |
| `/ko/learn` | 学習。単語 → 文 → 産出 → 仕上げ の順に自動で進む。画面下にハングルのキーボード。文の「解説」は押したときだけ AI が作る |
| `/ko/words` | 単語帳。レベル・ユニット・状態（苦手を含む）で絞り込み（検索はすべての意味から）、「苦手を練習」。単語の詳細（意味とほかの意味・漢字・面ごとの状態・類語・取り違えた相手・出てくる文・履歴） |

URL の最初の部分が言語（今は `ko` だけ）。上部の「langlang › 韓国語」でポータルと言語のホームに戻れる。

学習画面のキー: 矢印キーで選ぶ、Space で読み上げ、Enter で「わからない」（入力の練習では送る）、Esc で中断。
入力の練習は、日本語や英語の入力モードのまま、キーボードの英字の位置で打つ（画面のキーボードがハングルに組み立てる）。韓→日訳だけは答えが日本語なので、日本語入力をオンにして打つ。
入力欄では ← → でカーソルを動かせ、文字をクリックした位置にも置ける。Backspace は字母を 1 つずつ消す（애 の後ろで Backspace → ㅔ で 에）。

## 環境変数

| 変数 | 意味 |
| --- | --- |
| `LANGLANG_PORT` | 画面のポート。未設定なら 8766 |
| `LANGLANG_ROOT` | リポジトリのルート。未設定ならカレントディレクトリ |
| `LANGLANG_CLAUDE_BIN` | 使う claude バイナリ。未設定なら PATH 上の `claude` |
| `LANGLANG_CLAUDE_MODEL` / `LANGLANG_CLAUDE_EFFORT` | すべての用途のモデルと effort |
| `LANGLANG_<用途>_MODEL` / `_EFFORT` | 用途（TAG / ENRICH / VERIFY / GRADE / EXPLAIN）だけの上書き |
| `ANTHROPIC_API_KEY` | 設定しない。設定されていると API 課金に切り替わるため中断する |
